# Space Riders: Liberty Slugger Sports Arena

A free retro arena sports game on a giant meteor near Pluto, hosted by Liberty Slugger. Play 2-on-2 rocket hoops, a home run derby, 7-on-7 football with play-calling, zero-G soccer, comet hockey and space golf with planet gravity. Climb each sport's ladder for its trophy, face the Derby King in the final home run derby, and win every trophy for a numbered Certified Victor poster.

Plays on PC (keyboard, mouse or gamepad) and phones (on-screen controls).

Play: https://sanyziahj.github.io/liberty-slugger-sports-arena/
